# Nord / Blue Blizzard theme

Complementary components used across this setup:

- **GTK**: `nordic-theme-git` (set via `nwg-look` / gsettings)
- **Icons**: `Tela-circle-nord`
- **Cursor**: `nordzy-cursors` (AUR)
- **Terminal (Ghostty)**: Nord palette
- **Neovim**: `shaunsingh/nord.nvim`
- **tmux**: [`nordtheme/tmux`](https://github.com/nordtheme/tmux) (configured in `dot_config/tmux/tmux.conf`)
- **Firefox / Floorp**: [`dragonejt/nord-firefox`](https://github.com/dragonejt/nord-firefox) — apply the userChrome/userContent files to the active Floorp profile (`~/.floorp/<profile>/chrome/`)
- **Status bar**: eww with Nord palette (`dot_config/eww/`)
- **Shell prompt**: Starship with Nord palette (`dot_config/starship.toml`)
